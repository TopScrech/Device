# Device Neural Engine configurations

Device-level counts take precedence over chip-wide descriptions
Nominal storage capacities are explicit GB values, never estimates from formatted or available disk space
Unknown storage returns the distinct possible counts; an unsupported explicit capacity returns nil
Devices without a mapping retain the existing CPU fallback
